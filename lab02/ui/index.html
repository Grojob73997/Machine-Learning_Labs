Run your lab in PyCharm

  1. Open open_ui.py and click Run to open this interface.
  2. Open any file from src/task-1.py through src/task-7.py. A later task runs its prerequisites automatically.
  3. After changing the model code, run src/build_ui.py, then refresh this page to update all results.

This interface works offline. Its predictions use the real exported model weights. Changing the selectors switches between the six completed experiments; it does not retrain a model.

The timing values measure Python forward and backward passes on this computer, not browser rendering.
